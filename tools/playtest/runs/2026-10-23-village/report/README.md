# Отчёт ИИ-плейтеста Деревни (2026-10-23)

Страница: https://claude.ai/artifact/GYkp3js12zpt6qqs9MGH85 (приватная; поделиться — меню Share на странице).

Копия страницы и её данных:
- `index.html` — страница отчёта. Работает только внутри страницы-дашборда claude.ai: берёт данные через её `dash` (`dash.data`, `dash.calc`), отдельно в браузере не откроется.
- `playtest-village.json` — попытки 7 портретов × 10 уровней (из `../data.json`, собрано `node tools/playtest/report.js tools/playtest/runs/2026-10-23-village`).
- `tolerance-village.json` — допуск решений (из `../tolerance.txt`, `node tools/tolerance.js Деревня`).
- `target-sawtooth.json` — целевой коридор «пилы»: ориентир, а не измерение (форма — исследование ELIMINATION, пороги — правило индустрии, см. `tools/playtest/README.md`).
- `findings-village.json` — находки с числом портретов; те же пункты — в `RELEASE_PLAN.md`, этап 0.

На странице: вывод и плитки (кто ушёл бы, доля уровней с первой попытки, подсказки, скука); кривая сложности против целевой пилы; таблица «кто где споткнулся»; допуск решений; итог по портретам; находки.
