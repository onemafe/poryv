## Где мы сейчас
- Один файл `Порыв.html` (~120 КБ), Canvas 2D, без библиотек, без git.
- 15 уровней (6 обычных + 9 «режимов»: снег, дым, ветряки, ворота, вырубка, палатки, смена ветра…) и песочница.
- Уровень — это данные: `fixed` (что стоит), `inv` (что дают), `solution` (проверенная расстановка). Симуляция детерминированная (`createSim` → `runStep` → `evaluate`), значит, решения можно проверять программой.
- Управление: мышь и тач, есть узкая вёрстка. Сохраняется только список пройденных уровней (localStorage).
- Нет: звука, прогрессии (все уровни открыты), SDK площадки, английского, карточки. Шрифты грузятся с Google Fonts — для площадки их нужно положить внутрь игры.
