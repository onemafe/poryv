## Где мы сейчас
- Один файл `Порыв.html` (~120 КБ), Canvas 2D, без библиотек, без git.
- 15 уровней (6 обычных + 9 «режимов»: снег, дым, ветряки, ворота, вырубка, палатки, смена ветра…) и песочница.
- Уровень — это данные: `fixed` (что стоит), `inv` (что дают), `solution` (проверенная расстановка). Симуляция детерминированная (`createSim` → `runStep` → `evaluate`), значит, решения можно проверять программой.
- Управление: мышь и тач, есть узкая вёрстка. Сохраняется только список пройденных уровней (localStorage).
- Нет: звука, прогрессии (все уровни открыты), SDK площадки, английского, карточки. Шрифты грузятся с Google Fonts — для площадки их нужно положить внутрь игры.

## Куда выпускаем
- **Первая площадка — VK Игры.** Яндекс Игры сейчас закрыты для новых игр (удары по дата-центрам, сроков нет).
- Яндекс — вторым архивом из того же кода, когда откроется. Поэтому всё платформенное — только через слой `platform` (этап 1).

### Режимы — решение (2026-10-20)
- **Оставляем:** Занос (снег), Вырубка (связать с остальными режимами), Энергия (ветряки: выработать N энергии, направляя ветер к ним). Обычные механики (тень, щели, арка, клин, ротонда, труба котельной) — тоже.
- **В архив:** Смена ветра (тяжело держать в голове два поля ветра), Дым, Рельеф, Летящие предметы (Кемпинг), Сцепка (Слободка), Управление (Шлюз). Уровни — в `ARCHIVE` в `Порыв.html`, видны только с `?dev`; код механик не удалён.
- Энергия — только в главе с ветряками, как обязательная цель уровня. Звёзд-бонусов за энергию нет.
- Главы — по 8 уровней. Черновик: Деревня → Город → Мыс (ветряки + вырубка) → Перевал (снег + вырубка, финал «Большой шторм»). 4 главы = 32 уровня.
- **Смена ветра — не режим, а тип уровня** (решение 2026-10-20): может встретиться в любой главе. Оба ряда стрелок видны заранее (жёлтые «сначала», синие «через N с»). Уже есть: «Переменчивый ветер» (Деревня), «Сквозняк» (Город · черновик).
- **Плетень vs забор** (решение 2026-10-21): забор держит до **22 м/с** (было 26), плетень не ломается никогда. Плетень вводится в финале Деревни «Буря» (28 м/с): на открытом месте забор ломается, плетень — нет; забор ставят за деревья. Старые «Плетень» и «Перед бурей» удалены (разница с забором была не видна, у забора в финале было 2 рабочих места из 113), «Ветер с реки» — тоже (повтор забора). Деревня — 7 уровней.
- Реплики жителей — окном перед уровнем (кнопка «Начать»), пока уровень не пройден; в журнале их больше нет.
- **Допуск уровня** — `node tools/tolerance.js <глава или уровень>`: в скольких местах может стоять каждая фигура решения. 1–3 места = «подбирать до клетки». Урок из «Бури»: укрытия рядом разгоняют ветер в просветах — группы укрытий разносить, дом ставить за серединой забора. На грани сейчас «Крепкий сосед» (по 3 места у деревьев).
- **Шлюз** вернулся в «Режимы · черновик» как тестовый режим: ветер с запада — ворота закрыть, повернул с востока — открыть, иначе через 7 с заклинит (= провал). Старый шлюз с порывами — в архиве.
- Плейтест: уровень 2 не проходится — слишком резкий скачок. Нужны: плавная кривая, больше фиксированных объектов-подсказок, меньше фигур на расстановку.

## Этап 3. Уровни — главная работа (самый долгий этап)
15 уровней — это ~30–60 минут. На старте нужно **40+**, дальше — новые уровни обновлениями.
- [ ] **Проверка уровней программой:** скрипт (Node, без браузера) берёт уровень, ставит `solution`, гоняет симуляцию, вызывает `evaluate` → «решается / не решается». Плюс проверка, что уровень **не** решается пустым полем или половиной фигур (иначе слишком легко).
- [ ] Редактор уровней в игре (режим разработчика): расставить `fixed`, задать `inv` и ветер, сохранить решение кнопкой → JSON в `levels/`.

- [ ] Порядок: сначала растянуть первую главу (5–8 лёгких уровней — первая сессия решает всё), потом остальные.

## Этап 4. Деньги (1–2 вечера)

За награду — только по нажатию, награда названа в кнопке, кнопку показывать, только если реклама готова (`VKWebAppCheckNativeAds`). Свой лимит показов за награду в час и в сутки.
