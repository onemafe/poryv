# Порыв

Головоломка про ветер: игрок расставляет фигуры на острове, чтобы постройки пережили порыв. Canvas 2D, без библиотек, один файл `Порыв.html`.

**План до релиза и правила работы — [RELEASE_PLAN.md](RELEASE_PLAN.md). Работай по нему, этапами по порядку.**

## Устройство
- Уровень — данные: `fixed` (что стоит), `inv` (что дают игроку), `solution` (проверенная расстановка).
- Симуляция детерминированная: `createSim` → `runStep` → `evaluate`. Решения можно проверять программой.
- Экраны: загрузка → карта островов (глава = остров) → уровень (полоса сверху, «журнал» с фигурами снизу/справа). После загрузки — остров текущего уровня крупно и «Играть» внизу (у новичка это Деревня и обучение первого уровня).
- Прогресс — звёзды по названию уровня в localStorage `poryv-stars-v1`. Звёзды считаются от `PAR` — запаса прочности проверенного решения; после правки уровня запусти `node tools/check-levels.js` (`--fix` перепишет `PAR`). Насколько решение «до клетки» — `node tools/tolerance.js <глава>`; все решения и где стоят фигуры — `node tools/solve.js <уровень>`; для уровней вырубки (что рубить и где строить) — `node tools/forest.js <уровень>`. Все три принимают вторым аргументом файл черновиков из `tools/drafts/`.
- Тексты уровней (название, подсказка, диалоги, совет, вступления островов) и реплики обучения и уроков (`LESSONS` в игре, подстановки в `{…}`) пользователь правит в `Тексты.html` (открывается файлом в Chrome/Edge, без сервера): «Сохранить в игру» сразу пишет в `Порыв.html`. Левый столбец — тексты до всех правок из `tools/texts/original.json` (не перезаписывать), справа — игра в рамке: `Порыв.html?dev&level=<название>` открывает уровень как в первый раз, прогресс не пишет. Разбор и запись — `tools/texts/core.js` (общий с node). В `tools/texts/edits.json` остаются заметки пользователя к уровням и правки-конфликты; посмотреть — `node tools/texts/texts.js`. Если пользователь просит «посмотри мои заметки» — читай этот файл.
- `?dev` в адресе — все острова открыты, архив режимов, инструменты в паузе.
- `?agent=<имя>` — режим ИИ-плейтеста: агент `playtester` играет по скриншотам в роли портрета игрока, свой прогресс, `window.agent`. Как запускать — [tools/playtest/README.md](tools/playtest/README.md).

## Правила кода
- Симуляция идёт каждый кадр — на слабых телефонах важна каждая миллисекунда. Не утяжеляй без замера.
- Всё, что зависит от площадки (реклама, сохранения, язык, соцфункции), — только через слой `platform` (появится в Р1 плана).
- Секретов в коде нет и не должно быть.

## Публикация
- Каждый пуш в `main` выкладывает игру на GitHub Pages: https://onemafe.github.io/poryv/
- Workflow: `.github/workflows/pages.yml` (копирует `Порыв.html` → `index.html`). Vite не используем; архив для Яндекса Игр собирает скрипт (Р1 плана).
